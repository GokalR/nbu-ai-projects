# Презентация

## Как запустить

Распакуйте проект и откройте `index.html` в браузере. Папка `assets` должна находиться рядом с ним.

Для запуска через локальный сервер установите Node.js 18 или новее и выполните в папке проекта:

```sh
npm start
```

Откройте [http://localhost:8080](http://localhost:8080). Устанавливать зависимости и выполнять сборку не нужно. Остановка сервера — `Ctrl+C`.

## Как пользоваться

| Действие | Клавиша |
| --- | --- |
| Следующий этап или слайд | `→` или `Пробел` |
| Предыдущий этап или слайд | `←` |
| Первый / последний слайд | `Home` / `End` |
| Полный экран | `F` |
| Смена темы | `D` |
| Заметки ведущего | `N` |
| Запуск / остановка таймера | `T` |

Кнопки управления находятся справа внизу. На демонстрационных слайдах сначала переключаются этапы, затем открывается следующий слайд.

## Файлы проекта

```text
├── index.html              # Все слайды
├── assets/
│   ├── css/styles.css      # Все стили
│   ├── js/app.js           # Навигация и интерактивность
│   ├── images/             # Изображения
│   └── fonts/              # Шрифты
├── server.mjs              # Локальный сервер
├── package.json            # Команда запуска
├── .gitignore
└── README.md
```
